# Prometheus & Grafana Infrastructure Monitoring

Система мониторинга серверной инфраструктуры с визуализацией метрик и автоматическим оповещением о проблемах.

## 🛠 Стек технологий
*   **Prometheus** (сбор и хранение метрик)
*   **Node Exporter** (сбор системных метрик Linux)
*   **Grafana** (визуализация и дашборды)
*   **Alertmanager** (маршрутизация алертов)
*   **Telegram API** (доставка уведомлений)

## 🏗 Архитектура
*   Node Exporter собирает метрики CPU, RAM и дисков.
*   Prometheus опрашивает Node Exporter каждые 15 секунд.
*   Grafana подключается к Prometheus для отрисовки графиков.
*   При превышении порогов (например, CPU > 80% в течение 3 минут) Grafana отправляет алерт в Telegram.
